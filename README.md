This repository serves as a comprehensive collection of all projects, challenges, and architectural exercises completed during Jonas Schmedtmann's **"The Ultimate React Course"** on Udemy. It documents my transition from building basic components to architecting professional-grade applications using modern state management and frameworks like Next.js.

## 🚀 Technical Core
*   **Core Library:** React (Vite & Next.js)
*   **State Management:** Context API, Redux Toolkit, React Query
*   **Styling & UI:** Tailwind CSS, Styled Components, CSS Modules
*   **Routing:** React Router (v6.4+ Data Loading) & Next.js App Router
*   **Backend Services:** Supabase (Auth, DB, Storage)
*   **Development Workflow:** Git with Conventional Commits

## 📁 Repository Structure

This repository follows the same structure as Jonas's original course repo:

- `00-setup/` — Initial setup
- `01-pure-react/` — Pure React basics
- `02-JS-review/` — Modern JavaScript review
- `03-pizza-menu/` — First React project
- `04-steps/` — Component patterns
- `05-travel-list/` — State management
- `06-eat-n-split/` — Practice project
- `07-usepopcorn/` — Custom hooks & data fetching
- `08-how-react-works/` — How React works internally
